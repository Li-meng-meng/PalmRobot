# firmware/ — ESP32 固件（机器人本体）

> 详细方案见 [`docs/12-嵌入式方案.md`](../docs/12-嵌入式方案.md)
> 机器人本体就是**产品本身**：基础硬件 + **WiFi / 蓝牙 / 串口的指令服务**（只收发小文本）。

---

## 机器人负责什么

| 负责 | 不负责 |
|---|---|
| 舵机实时控制 | 视频处理 |
| 步态与动作播放 | 图片 / 表情识别 |
| 表情渲染 | 通用物体识别 |
| 安全保护（悬崖 / 堵转 / 低电） | 需要算力的任何事 |
| 接收指令、回传状态 | — |

**机器人只接收小文本**（指令几十字节、动作包 2–10 KB），**永不接收视频或图片**。

---

## 技术栈（全部现成库）

| 用途 | 库 |
|---|---|
| 框架 | ESP32 Arduino Core |
| 舵机 | Adafruit_PWMServoDriver（PCA9685） |
| TCP / WebSocket 服务 | ESPAsyncWebServer（**仅做通信，不提供网页**） |
| 蓝牙 | ESP32 BLE 库（V3 配网用） |
| 显示 | Adafruit_SSD1306 + Adafruit_GFX |
| JSON | ArduinoJson |
| 文件系统 | LittleFS |
| OTA | ArduinoOTA |
| 调度 | FreeRTOS（ESP32 自带） |

> **重要**：ESPAsyncWebServer 只用来跑 TCP/WebSocket 通信，**不做网页控制台**（已决定取消网页端）。

---

## 引脚分配（建议）

| 功能 | 引脚 | 说明 |
|---|---|---|
| I2C SDA / SCL | GPIO 8 / 9 | 接 PCA9685 + OLED + 扩展口 + 运动模块口 |
| 电池电压检测 | ADC | 分压电阻 |
| 悬崖检测 ×2 | ADC 或 GPIO | 红外对管（约 ¥3/只） |
| 状态 LED | GPIO | |
| 串口调试 | UART0 | 烧录与命令行调试 |

**8 路舵机全部走 PCA9685，不占用 MCU 的 PWM**；PCA9685 还剩 8 路可给扩展舵机（尾巴 / 云台 / 夹爪）。

## 固件模块

| 模块 | 职责 |
|---|---|
| 动作解释器 | 解析 `.motion`，按时间轴驱动通道 |
| 舵机调度 | 限速、限流、限制同时动作数（**保护电源**） |
| 表情渲染 | 12 维参数 → 128×64 帧，含缓动 |
| 姿态管理 | 站立 / 趴下等状态切换与安全过渡 |
| **指令服务** | WiFi / 串口 / 蓝牙接收小文本指令 |
| 状态回传 | 电压、温度、姿态、错误码 |
| 安全守护 | 悬崖检测、堵转超时、低电保护、看门狗 |
| 配置存储 | LittleFS 保存参数、动作包、WiFi 凭据 |

### FreeRTOS 任务分配

| 任务 | 优先级 | 说明 |
|---|---|---|
| 看门狗 | 最高 | 异常复位 |
| 舵机刷新 | 高 | 20 ms 周期，**不能被网络阻塞** |
| 动作解释 | 高 | 按时间轴推进关键帧 |
| 表情渲染 | 中 | 10–20 fps |
| 网络收发 | 中 | 独立核 |
| 状态采集 | 低 | 每秒一次 |

> **舵机刷新必须与网络分核**，否则 WiFi 一忙动作就卡顿。

## 配网（无网页端）

取消了网页端，所以不能再走"连热点 + 浏览器打开页面"那套：

| 阶段 | 方式 | 实现 |
|---|---|---|
| P0 | 编译时写死 SSID / 密码 | 只做几台样机，够用 |
| P1 | **串口配网** | 上位机发 `WIFI <ssid> <pwd>` → 存 LittleFS → 重启 |
| P2 | 保留串口配网 | |
| V3 | **蓝牙配网** | App 通过 BLE 发送凭据 |

**连接失败必须自动回退**到"等待配网"状态并提示，否则用户换路由器后设备永久卡死。

---

## 必须记住的三条

1. **舵机必须 180° 版本**（360° 版无法定位角度，整机不可用）
2. 电源轨并 **1000 µF 电容** + 软件限制同时动作舵机数（8 舵机峰值 5.6–8 A，3 A 电源会被拉垮）
3. 固件要提供**单舵机中位标定**（SG90 批次差异 5–10°）

---

## 明确不做

| 不做 | 原因 |
|---|---|
| **机器人端视觉** | **ESP32-C3 没有摄像头接口（无 LCD_CAM），也不支持 PSRAM** |
| 网页控制台 | 已决定取消网页端 |
| 本地 AI 推理 | 芯片不支持 |

> **若要加摄像头**，必须换 **ESP32-S3 + PSRAM**（+¥20–30）或加视觉协处理器（+¥30–45）。
> 唯一值得加的理由是玩法需要**低延迟**（追球、跟随人、实时避障）。**这是采购前必须定的事。**
