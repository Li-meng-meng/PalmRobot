# PalmRobot · 掌上模块化机器人

一只**掌心大小、能走能演，还能学你动作精华和表情**的开源机器人。

核心设计是**模块化运动平台**：同一个本体，换运动模块即可在四足 / 轮式 / 履带 / 双足之间切换。

---

## 三个部分

| 部分 | 是什么 | 负责 |
|---|---|---|
| **上位机**（软件） | 大脑：电脑端 WPF + App MAUI | 控制、视频处理、图片处理、设置、仿真 |
| **机器人本体**（嵌入式 + 硬件） | 身体：ESP32 + 舵机 + OLED | 执行动作、表情、安全保护 |
| **设计** | 外壳：造型、配色、接口开孔 | 工业设计 |

**关键约束：机器人只收小文本指令（几十字节到几 KB），永不接收视频或图片。**
