# tools/ — 工具脚本（Python）

这些脚本看起来小，但每次开团都会用到，是"写一次省半天"的东西。

## 计划中的工具

| 脚本 | 用途 | 工时 | 阶段 |
|---|---|---|---|
| `motion_gen.py` | 生成 / 校验 `.motion` 动作文件 | 2 天 | P0（优先） |
| `calibrate.py` | 连机器人 → 微调舵机中位角 → 生成配置 | 3 天 | P1 |
| `orders.py` | 导出订单 → 生成采购清单 / 装配工单 / 发货清单 | 2 天 | P1 |

## 为什么值得写

- 两人团队最大的瓶颈是**重复劳动**
- 处理 20 单：手工要 1 小时，脚本 5 分钟
- 标定工具能把每台机器人的出厂时间压到 10 分钟内
