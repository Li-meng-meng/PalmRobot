# ai/ — AI 能力

**所有 AI 都跑在手机/电脑上，机器人只负责播放动作**（它只有 ESP32，跑不动视觉模型）。

## 三条线

| 能力 | 原型（Python） | 落地（JS） | 阶段 |
|---|---|---|---|
| 视频动作提取 | MediaPipe Pose + NumPy | MediaPipe Pose Landmarker (Web) | P2 / V2.5 |
| 表情镜像 | MediaPipe Face Landmarker | 同左 | P2 |
| 音乐打拍 | librosa | Web Audio API | P2 |

## 核心原则：提取精华，再表达

> 8 个自由度不可能复刻人体动作。我们的做法是**从视频里提取"动作精华"，再用机器人的身体重新表达**。
> **能做的就做，做不了的就摇摆** —— 保证任何视频都能生成结果。

## 7 类精华特征

节拍/速度、能量/强度、方向、周期性、高度变化、情绪倾向、段落结构。

## 最重要的工程约定

> **映射表（精华特征 → 机器人动作）存成一份 JSON，Python 和 JS 读同一个文件。**
>
> 映射表是产品核心资产、一定会反复改。两边各写一份逻辑必然漂移，这是双语言方案最大的坑。

## 兜底原则

不允许出现"分析失败，无法生成"。识别质量再差，也至少靠节拍与能量生成一段律动。
