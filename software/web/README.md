# web/ — 3D 预览组件

> **这不是产品形态。**
> 原计划的"用户网页控制台"已取消（改为原生上位机）。本目录只剩一个用途：
> **被上位机用 WebView2 内嵌，做动作的 3D 预览。**

---

## 用途

| 用途 | 说明 |
|---|---|
| 动作编辑器预览 | 调关键帧时实时看到机器人姿态 |
| 步态检查 | 把仿真输出的角度序列可视化 |
| 演示素材 | 录屏做演示视频 |

**谁用它**：`software/desktop/` 的 WPF 上位机。

---

## 技术栈

| 用途 | 用什么 |
|---|---|
| 3D 渲染 | **three.js** |
| 模型加载 | three.js 的 `STLLoader`（加载 sesame 的 STL） |
| 运动学 | 自己写腿部正运动学（每条腿 2 舵机 → 2 段连杆，本质是三角函数） |
| 与上位机通信 | WebView2 的 JS Interop |

**不需要物理引擎** —— 预览只验证"角度序列看起来对不对"，这是运动学问题。

---

## 模型从哪来

| 资产 | 来源 |
|---|---|
| STL 零件 | `dorianborian/sesame-robot` → `hardware/printing/stl/`（**原版单个零件 350–390 KB，需要减面**） |
| 参考 | GitHub 搜 "three.js quadruped" 有现成演示可借鉴运动学部分 |

---

## 关键约束

| 约束 | 说明 |
|---|---|
| **不需要离线可用** | 它跑在上位机里，不受 ESP32 的 flash 限制 |
| 模型要减面 | 原版 STL 太大，减到 5% 面数足够预览 |
| 锁定 three.js 版本 | API 变化较快 |
| 不做成网页产品 | 不要再加遥控、设置之类的功能 |
