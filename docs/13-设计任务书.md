# 设计任务书（外壳）

> 配套《10-总体规划》。交付对象：外观设计（兼职 / 外包）。
> **核心原则：不从零设计，复用 sesame 的现成结构，只改外壳。**

| 项目 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-16 |
| 预算 | 首版 ¥0（概念草图）；建模按后续预算 |

---

## 1. 任务目标

给机器人做出**一眼能认出的角色形象**，同时**不触碰腿部机构**。

| 要达成 | 不要做 |
|---|---|
| 有辨识度的头部与身体造型 | 改腿部连杆结构 |
| 屏幕窗口开在合理位置 | 改舵机安装位 |
| 2–3 套配色 | 改舵盘连接方式 |
| 预留扩展接口开孔 | 设计复杂曲面（打印失败率高、代打贵） |

> **为什么不能改腿**：改腿部结构意味着步态要重新调参（1–2 周工时）。团队是 ¥300 启动、2 个工程师，没有这个余量。

## 4. 设计约束（必须遵守）

### 4.1 尺寸与重量

| 项 | 约束 |
|---|---|
| 最长边 | ≤ 150 mm（掌上尺寸） |
| 整机重量 | ≤ 450 g |
| OLED 窗口 | 可视区约 **27 × 27 mm**，开在头部正面 |

### 4.2 接口开孔位置

| 接口 | 位置 | 说明 |
|---|---|---|
| 扩展口 ×2 | **背部 1 + 头部 1** | 磁吸定位 + 2×M2 螺丝 + 4pin 弹簧针 |
| 运动模块口 ×1 | **底部** | 4pin（5V/GND/SDA/SCL），与扩展口同规格 |
| 充电 / 串口 | 侧面 | 预留开孔与挡板 |
| 电源开关 | 顶部或侧面 | 便于触达 |

### 4.3 打印与装配要求

| 检查项 | 标准 |
|---|---|
| 最小壁厚 | ≥ 1.2 mm（承力处 ≥ 2 mm） |
| 螺丝柱 | 外径加厚，孔留 **0.2–0.3 mm 公差** |
| 悬垂角度 | > 45° 需加支撑（尽量避免） |
| 舵机安装位 | 留 0.2–0.3 mm 间隙 |
| 零件数 | 尽量少（每多一件都增加装配时间与代打成本） |

### 4.4 可维护性

| 要求 | 说明 |
|---|---|
| 单个舵机可独立更换 | 目标 10 分钟内完成，不必拆整机 |
| 螺丝规格统一 | 统一 M2，一把十字螺丝刀可全拆 |
| 外壳可开合 | 便于调试，不要一体封死 |

## 5. 角色方向（供选择）

| 方向 | 为什么推荐 | 动作语言 |
|---|---|---|
| **鸭 / 鹅**（首推） | 摇摆步态天然喜感，与四足笨拙感契合 | 摇摇摆摆、摆尾、点头 |
| **企鹅** | 圆润、黑白配色好做 | 左右摇摆、歪头 |
| **恐龙 / 小怪兽** | 受众广（含儿童），表情可夸张 | 跺脚、装死 |
| **水豚** | 当下流行，反差感强 | 慢动作、躺平 |
| **狗**（标准款） | 认知度最高、最容易解释 | 全套经典动作 |

> **战略建议**：做"非狗生物"能立刻脱离"又一个开源机器狗"的同质化，**成本不变、护城河变宽、内容更容易出圈**。

## 6. 换壳测试（零成本验证角色）

**正式建模前先做这一步。**

| 项 | 内容 |
|---|---|
| 做什么 | 同一台样机硬件，打 3 套极简外壳（狗 / 鸭 / 企鹅） |
| 怎么做 | 各拍一条 15 秒视频，**同一天**发小红书和 B 站 |
| 看什么 | 完播率与互动量 |
| 投入 | 代打 3 套约 ¥120–240（蹭到打印机接近 ¥0） |
| 产出 | **用真实数据决定产品角色**，而不是猜 |

## 7. 工具与能力要求

| 等级 | 能力 | 学习成本 | 本项目需要吗 |
|---|---|---|---|
| L1 | 下载 STL 直接打印 | 半天 | 够 P0 |

| 工具 | 难度 | 适合 |
|---|---|---|
| **Tinkercad** | 低 | 改现成模型（浏览器里用） |
| **Fusion 360 个人版** | 中 | 参数化功能件（免费） |
| Blender | 高 | 角色曲面造型 |

## 8. 时间与里程碑

| 阶段 | 交付 | 时间 |
|---|---|---|
| P0 第 1–2 周 | 概念草图 2–3 个方向 | |
| P0 第 3–4 周 | 选定方向 + 换壳测试 | |
| P0 第 5–8 周 | 用 sesame 原版 STL 装配验证（不改） | |
| **P1** | 头部 + 身体外壳、配色、接口开孔 | |
| P2 | 摄像头预留孔、包装视觉 | |

> **P0 阶段不要急着改造型**：先用原版 STL 把装配跑通，才知道哪些地方必须改。直接上手改造型，会同时面对"装配不通"和"造型不对"两个问题。

## 9. 与其他角色的接口

| 对接方 | 需要确定的事 |
|---|---|
| **嵌入式** | 舵机安装位、螺丝孔位、外壳与舵机的机械接口、开孔尺寸 |
| **软件** | 无直接接口（但需知道动作幅度，以便外壳不被撞到） |
| **采购** | 打印方式（自有 / 代打）、耗材、配色 |

**第 1 周必须冻结**：外壳与舵机的机械接口（安装位、舵盘、螺丝规格）。

## 10. 验收标准

| # | 标准 |
|---|---|
| 1 | 能在不拆整机的前提下 10 分钟内更换单个舵机 |
| 2 | OLED 表情清晰可见，不被外壳遮挡 |
| 3 | 扩展接口开孔位置准确，弹簧针接触良好 |
| 4 | 打印件一次成型良率 ≥ 80%（不需要二次修配） |
| 5 | 整机重量 ≤ 450 g |
| 6 | 脚底防滑垫装好后在玻璃桌面不打滑 |
| 7 | 造型与已知 IP 无冲突 |

## 11. 风险

| # | 风险 | 对策 |
|---|---|---|
| D1 | 改了腿部结构导致步态重调 | **只改外壳**（本文件第 1 节） |
| D2 | 屏幕窗口太小，表情看不清 | 可视区 ≥ 27×27 mm |
| D3 | 打印公差导致舵机装不进 | **先打 1 套试装，再批量** |
| D4 | 造型复杂导致打印失败率高、代打贵 | 避免大悬垂与细长结构 |
| D5 | 撞已知 IP 造型 | 避免酷似皮克斯 / 迪士尼角色 |
