# 21 - 动作文件格式规范（.motion，v1.0 冻结）

> **状态：冻结。** 配套《20-指令集规范》。由软件侧定义、嵌入式实现解释器、上位机生成与编辑。
> 文件是**可独立分享的最小单元**（2–10 KB），即"动作包"。

| 项目 | 内容 |
|---|---|
| 格式版本 | v1（`version` 字段 = 1） |
| 编码 | UTF-8，无 BOM |
| 扩展名 | `.motion` |
| 大小约束 | 2–10 KB（硬上限 16 KB，与指令集 `PUTM` 一致） |
| 校验工具 | `python software/tools/motion_gen.py validate <file>` |

---

## 1. 顶层结构

```json
{
  "name": "wave",
  "version": 1,
  "duration_ms": 2000,
  "loop": false,
  "tracks": {
    "servo": [ { "t": 0,    "ch": [90,90,90,90,90,90,90,90] },
               { "t": 400,  "ch": [90,60,90,120,90,90,90,90] } ],
    "face":  [ { "t": 0,    "expr": [80,10,60,40,30,90,60,50,0,0,40,80] } ],
    "audio": [ { "t": 500,  "clip": "bark.wav" } ]
  },
  "meta": { "author": "software", "source": "manual", "tags": ["greeting"],
            "created": "2026-09-17" }
}
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `name` | string | ✅ | 1–32 字符，`[a-z0-9_-]`，全仓库唯一 |
| `version` | int | ✅ | 必须为 `1` |
| `duration_ms` | int | ✅ | 100–600000（0.1 s–10 min） |
| `loop` | bool | ✅ | 循环播放标志 |
| `tracks` | object | ✅ | 至少含 `servo`；`face` / `audio` 可省略 |
| `meta` | object | ❌ | 缺省时解析为空对象 |

---

## 2. 轨道（tracks）

### 2.1 servo 轨道（必需）

| 字段 | 约束 |
|---|---|
| `t` | 关键帧时刻，0 ≤ t ≤ duration_ms，**非降序** |
| `ch` | **恰好 8 个**角度，0–180 整数，中位 90；通道序同指令集 §5.2 映射 |

- 相邻帧最小间隔 **20 ms**（固件舵机刷新周期，更密无意义）。
- `t=0` 必须有第一帧（定义初始姿态）。
- 播放时固件在关键帧间**线性插值**；`loop=true` 时末帧向首帧循环插值。

### 2.2 face 轨道（可选）

| 字段 | 约束 |
|---|---|
| `t` | 同上，非降序，与 servo 轨道独立 |
| `expr` | **恰好 12 个**整数，语义与顺序见指令集 §6（1–11 为 0–100，第 9/10 位 gaze 为 -100–100） |

### 2.3 audio 轨道（可选）

| 字段 | 约束 |
|---|---|
| `t` | 同上 |
| `clip` | 文件名 ≤ 32 字符，`[a-z0-9_-]`，**仅是触发点引用**；音频文件本体另行下发（P0 不实现，保留字段） |

## 4. 校验规则（嵌入式与上位机共同实现）

固件收到 `PUTM` 与上位机导入文件都必须按此清单校验，任一失败拒绝并报 `ERR 11 CHECKSUM`（固件侧）：

1. JSON 可解析，顶层为对象，`version == 1`
2. `name` / `duration_ms` / `loop` / `tracks.servo` 存在且类型正确
3. 所有 `t` 为非负整数且 **非降序**
4. 所有 `ch` 数组长度为 8，值在 0–180
5. 所有 `expr` 数组长度为 12，值在各自范围
6. `tracks.servo` 非空且首帧 `t == 0`
7. 相邻 servo 帧间隔 ≥ 20 ms
8. 全部 `t` ≤ `duration_ms`
9. 文件总字节数 ≤ 16384

> **降级原则**：`face` / `audio` 轨道缺失不影响播放；servo 缺失才拒绝。

## 5. 预设姿态对应的关键帧（基准约定）

`POSE` 指令的预设姿态等价于固件内置的以下帧。**站立位以仿真资产 `assets/calibration/default.yaml` 的 `stand_degrees` 为基准**（ch 序同《20-指令集规范》§5.2：R1,R2,L1,L2,R4,R3,L3,L4），其余姿态在此基础上推导；实物标定后可微调。

| 姿态 | ch0..ch7（R1,R2,L1,L2,R4,R3,L3,L4） | 说明 |
|---|---|---|
| `stand` | 135 45 45 135 0 180 0 180 | 仿真标定站立位 |
| `sit` | 135 75 45 75 50 170 20 170 | 后腿折叠、前腿撑地 |
| `sleep` | 135 80 45 80 60 160 20 160 | 四腿收拢趴下，同时熄屏 |

## 6. 工具链

| 工具 | 用途 |
|---|---|
| `software/tools/motion_gen.py validate <file|dir>` | 校验单个或全部 `.motion` |
| `software/tools/motion_gen.py gen <preset> <out>` | 由预设生成动作文件（stand / wave / dance 等） |
| `software/tools/motion_gen.py beautify <in> <out>` | 缓动烘焙：Catmull-Rom 平滑 + 自适应采样，把关键帧拐角磨圆后按 ≤1° 容差重采样（见下） |
| `software/tools/motion_gen.py stats <dir>` | 汇总目录下动作包数量与大小 |
| `software/tools/make_dances.py` | 8 关节直接编排成套舞蹈 + CPG 生命感动作（idle 呼吸 / bounce 蹦跳），默认烘焙后落盘。优美度手法：脊柱波（前后膝相位错位）/ 正交 Lissajous 画圆 / 非对称包络 / 对角折叠词汇 |
| `software/tools/opencat_to_motion.py` | Petoi OpenCat 动作库（InstinctXxx.h）→ `.motion` 转换器，保留手势（重心/俯仰/蹲起），MIT 署名见工具头注释 |
| `simulation/motion_probe.py` | 动作可视幅度探针：仿真中量化身体高度区间 / 水平漂移 / 倾角区间（"摔不摔"之外回答"看得见吗"） |

**缓动在生成端烘焙，固件保持线性插值**：规范不变、固件不改，"好看"由工具链负责——
生成端把缓动曲线按最小帧间隔 20ms 采样成密关键帧，固件线性插值连线即得平滑曲线。
`beautify` 与 `make_dances.py` 默认启用；字节预算超限时自动放宽容差（上限 8°），目标 ≤10KB。

样例动作包位于 `software/tools/motions/`，作为三端（固件 / 上位机 / 预览组件）联调的共同测试资产。

| 类别 | 动作 | 生成方式 |
|---|---|---|
| 编排舞蹈 | `tai_chi` / `swan` / `cha_cha` / `waltz` / `moonflow` / `yoga` | `make_dances.py` 关节级编排 |
| CPG 生命感 | `idle`（呼吸）/ `bounce`（蹦跳） | 同上，参数化振荡器 |
| 互动情绪 | `yes` / `no` / `happy` / `act_cute` / `startled` / `bow` / `greet_show` | 同上，带 face 轨道（含 `greet_show` 多段表情切换） |
| OpenCat 转换 | `oc_*.motion`（25 个） | `opencat_to_motion.py`（源数据 MIT © Rongzhong Li） |
| 视频生成 | `bboy_steve` / `hand_gestures` 等 | `ai/` L1 律动 / L2 重定向 |

> **膝折叠方向勘误（2026-09-21，MuJoCo 实测校准）**：四膝折叠为 `R4 加 / R3 减 / L3 加 / L4 减`
> （左膝与右膝镜像，站立位在 0/180 端点，向中位收 = 下蹲）。此前 `make_dances.py` 与
> `opencat_to_motion.py` 左膝符号写反导致左膝恒在端点不动，已修正生成端并按镜像关系
> 迁移存量 `oc_*.motion`；全部动作包重新过仿真 42/42 PASS。
