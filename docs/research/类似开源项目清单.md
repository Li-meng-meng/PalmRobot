# 小型开源机器人清单：类似 MindPaw 与 Hugging Face 双足机器鸭

> 数据来源：GitHub 公开 API 检索 + 各仓库 README 正文核对，星标数截至 **2026-09-14**。
> 排序原则：**按体型从小到大**，小只的放最前面，体型大的统一收进最后的备查区。
> 尺寸可信度：标 ✅ 的是我从仓库 / 官方页面**实际核对到的数字**；标"官方自述"的是仓库自己写的定性描述（如 desktop-sized）；标"—"的表示仓库没有标注尺寸，这类 DIY 项目最终大小取决于你选的舵机和打印比例。
> 所有项目名都可点击跳转到 GitHub。

**要最小、最轻、还能走 —— 双足**
→ [pollen-robotics/microduck](https://github.com/pollen-robotics/microduck)（25 cm / 800 g）+ [pollen-robotics/microduck_rl](https://github.com/pollen-robotics/microduck_rl)；

## 七、几个值得注意的规律

1. **小体型的双足这一档，microduck 几乎没有对手**：25 cm / 800 g、Apache-2.0、官方 RL 环境和 MJCF 模型齐全，同尺寸的替代品基本都停在论文或原型阶段。
2. **小四足这一档反而很卷**：ESP8266/ESP32 方案多到挑不完，但绝大多数没有 AI 交互层——[ace-trump-tech/MindPaw](https://github.com/ace-trump-tech/MindPaw) 的差异化就在这里。
3. **想给任何小机器人加"会说话"的能力，现成的底座是 [78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)**，社区已经有把它接到桌宠、玩具狗、机械臂上的各种衍生项目。
4. **尺寸信息普遍缺失是个坑**：我核对了 20 多个仓库的 README，明确写尺寸/重量的只有极少数（microduck、microban、bimo、asimov-1）。DIY 项目最终多大，取决于你选的舵机和打印比例，别只看效果图。
