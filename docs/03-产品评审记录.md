---

## 1. 评审范围

本次评审只回答三个问题：

1. **这套最低成本方案，技术上是否走得通？**
2. **成本目标（A 档 ≤ ¥115）是否真实可达？**
3. **有哪些坑必须在动手前就避开？**

不在本次评审范围内：量产工艺、模具、销售渠道、认证合规。

---

## 2. 评审结论

> **有条件通过。** 方案主体成立，成本目标可通过"砍掉专用 PCB、改用手工接线 + 模块化采购"实现，预期能比参考项目降本 **约 65%–75%**。
>
> **本次修订（2026-09-15）**：已用国内电商实价替换全部早期估算。**A 档从 ¥82.5 修正为 ¥105.8**，原定 ≤ ¥90 的目标不成立，需修订为 ≤ ¥115。B 档从 ¥165 修正为 ¥151，目标仍成立。
>
> 但必须满足以下 3 个前置条件，否则方案不成立：
>
> | 条件 | 说明 |
> |---|---|
> | **C1** | M1 阶段先做**供电带载测试**，验证 8 舵机同时动作时 5V 轨不塌陷。这是最高风险项，不通就改电源方案 |
> | **C2** | 舵机必须确认是 **180° 版本**。参考项目专门警告过：买错成 360° 连续旋转款，整机直接不可用 |
> | **C3** | 复用 sesame 的 STL / 固件时，必须保留 Apache-2.0 的 LICENSE 与出处声明 |

## 3. 方案对比

### 3.1 四套方案横向对比

| 维度 | 参考项目 sesame | A 档 · 极限版 | B 档 · 标准版 | C 档 · 进阶版 |
|---|---|---|---|---|

| 供电 | 5V/3A USB-C PD 或 14500 电池 | 有线 5V/3A | 2S 18650 + 降压 | 同 B 档 |
| 专用 PCB | **有（需打样+贴片）** | 无 | 无 | 无 |
| 表情屏 | 0.96" OLED | 0.96" OLED | 0.96" OLED | 0.96" OLED |

| 物料成本（国内） | ≈ ¥310–420 | **≈ ¥106** | **≈ ¥151** | ≈ ¥250–280 |
| 装配难度 | 高（贴片焊接） | 低 | 中 | 中 |
| 适用人群 | 有经验的创客 | 先跑通流程 | 长期玩 | 做 AI 交互演示 |

### 3.2 评审意见

- **A 档是本次的核心价值主张**：它证明"同一只机器狗，砍掉专用 PCB、换塑料齿舵机、改有线供电"就能把成本压到参考项目的 1/4。
- **B 档才是可持续迭代的形态**：金属齿舵机 + 电池，寿命和体验都正常，成本仍只有参考项目的一半。
- **C 档不建议现在做**：语音/摄像头会引入新的功耗、算力和结构问题，放二期。

## 4. 关键决策点评审

### D1 · 自由度选 8 还是 12

| 选项 | 成本 | 能力 |
|---|---|---|
| **8 DOF（每腿 2 舵机）** | 舵机 ¥44（SG90）～ ¥60（MG90S） | 能走、能转向、能挥手、能坐下 |
| 12 DOF（每腿 3 舵机） | 舵机 ¥66 ~ ¥90 | 步态更自然，能做更复杂动作 |

**结论：选 8 DOF（通过）。**
12 DOF 会让成本、重量、调试难度同步上升，且参考项目已经验证 8 DOF 足够做出完整的产品体验。8 DOF 是本项目的成本与体验平衡点。

### D2 · 主控选型（本方案最关键的技术决策）

实测数据（来自 Espressif 官方文档）：

| 芯片 | LEDC PWM 通道 | 8 舵机是否够 |
|---|---|---|
| ESP32（经典 WROOM-32） | 16 | ✅ 余量充足 |
| ESP32-S3 | **8** | ✅ **刚好用满，零余量** |
| ESP32-S2 | 8 | ✅ 刚好用满 |
| ESP32-C3 | **6** | ❌ 必须外挂 PCA9685 |

| 候选方案 | 成本 | 评审意见 |
|---|---|---|
| ESP32-C3 + PCA9685 | **¥23.5**（¥13 + ¥10.5） | **A、B 档均采用**。16 路 PWM 余量最大，代价是多一个模块和多一层 I2C 通信 |
| ESP32-S3 SuperMini | **未取得可信报价** | 品牌板要 ¥69（DFRobot）～¥179（微雪带屏），平替最小系统板未查到实价，**本期不采用** |
| ESP32-WROOM-32 DevKit | 未核实 | **备选**。16 通道直驱，与参考项目的 Arduino 生态最兼容 |

**结论：A、B 档统一采用 C3 + PCA9685（修订）。**
原定"B 档改用 ESP32-S3 直驱"，但因 **ESP32-S3 未取得可信的平价报价**（品牌板 ¥69–179），且直驱方案会把 8 路 PWM 全部占满，故 B 档维持 C3 + PCA9685。

**补充发现（扩展性，2026-09-16）**：PCA9685 是 16 路，腿部只用 8 路，**剩余 8 路直接可用于扩展舵机**（尾巴、头部云台、夹爪），无需任何硬件改动。相比之下 ESP32-S3 直驱方案剩余 0 路，加一个尾巴就要改方案。

> 这条发现改变了 D2 的权重：选 PCA9685 不只是"省 ¥16"，而是**把可扩展性一起买回来了**。原"附加要求"（写明 PWM 用满）相应修订为："写明 **MCU PWM 已用满**，但 **PCA9685 尚有 8 路余量**，扩展舵机一律走 PCA9685。"

### D3 · 舵机选型

| 型号 | 参考单价 | 扭矩（典型值） | 齿轮 | 评审意见 |
|---|---|---|---|---|
| SG90 9g 180° | **¥5.5** | ≈ 1.8 kg·cm | 塑料 | A 档可用。便宜但**扫齿是常态**，属易损件 |
| MG90S 180° | **¥7.5** | ≈ 2.2 kg·cm | 金属 | B 档推荐。多花 ¥16，寿命显著提升 |

**结论：通过，但分档。** A 档用 SG90 接受"舵机是耗材"的现实，B 档用 MG90S。

**硬性要求（评审组特别强调）**：
1. 必须买 **180°** 版本。市面上大量 MG90S 是 360° 连续旋转版，买错直接不可用。
2. 9g 舵机**批次公差很大**，同一批不同个体中位角可能差 5°–10°。固件必须提供**单舵机中位标定**功能，不能写死角度。

### D4 · 供电方案

电流核算：

| 工况 | 电流估算 |
|---|---|
| 8 舵机待机 | ≈ 80 mA |
| 正常行走（3–4 个同时动作） | ≈ 1.2–2 A |
| 最坏情况（8 个同时堵转） | **≈ 5.6–8 A** |

| 候选方案 | 成本 | 评审意见 |
|---|---|---|
| 有线 5V/3A 电源 | ¥12（未核实） | **A 档采用**。最便宜，且省掉电池和充电管理 |
| 2S 18650 + 5V/3A 降压 | **≈ ¥41**（电池 ¥20 + 保护板/充电器 ¥15 + 降压 ¥6） | **B 档采用**。需配保护板 |
| USB-C PD 5V/3A（同参考项目） | 需 PD 诱骗 | 成本更高，本方案不采用 |

**结论：通过，但这是最高风险项。**
**必须执行**：电源轨并联 ≥1000 µF 电解电容；固件限制同时动作的舵机数量；M1 阶段先用示波器/万用表做**带载掉压测试**，通过后才允许进入结构阶段。

### D5 · 结构方案

| 方案 | 成本 | 评审意见 |
|---|---|---|
| 复用 sesame STL 打印 | ¥5 耗材 | **推荐**。Apache-2.0 允许，11 件套已验证可装配 |
| 自行建模 | ¥5 + 时间 | 二期再说，一期不重复造轮子 |
| 代打（嘉立创/淘宝） | ¥40–80 | 无打印机时的备选 |
| 亚克力切割 | ¥25–40 | 不推荐，舵机安装精度难保证 |

**结论：通过。** 一期直接复用参考项目 STL，把时间留给电气和步态调试。

### D6 · 固件路线

| 选项 | 评审意见 |
|---|---|
| 直接刷 sesame 固件 | ❌ 引脚定义基于 ESP32-S2，换 S3/C3 后不可直接用 |
| 复用其架构 + 改引脚 | ✅ 推荐。保留它的步态与表情逻辑，只改底层 |
| 从零自研 | ⏳ 二期。步态调参成本高，不值得一期重做 |

**结论：有条件通过。** 必须预留 **¥0 缓冲但 +2 天工期**用于引脚适配与联调。

### 5.2 降本来源拆解（相对参考项目）

| 降本手段 | 预计节省 | 影响 |
|---|---|---|
| 去掉专用 PCB（免打样贴片） | **−¥100 ~ −200** | 改用洞洞板/杜邦线，外观和可靠性略降 |
| 舵机降级 MG90S → SG90 | −¥16 | 寿命下降，视为耗材 |
| 电池 + 充电管理改为有线供电 | −¥41 | 失去无线能力，拖线运行 |
| 主控换成国产平价模组 | −¥0 ~ −40 | 需自行处理引脚差异 |
| 打印件自产 | −¥40 ~ −75 | 依赖自有打印机 |
| **合计** | **约 −¥200 ~ −¥310** | 降本后约为参考项目的 1/3 |

### 5.3 成本评审结论

- **A 档实测测算 ¥105.8，原定 ≤ ¥90 的目标不成立**，需修订为 **≤ ¥115**
- 修正原因：舵机单价从早期估算的 ¥3.5 修正为实价 **¥5.5**，8 个舵机直接多出 ¥16；PCA9685 从 ¥7 修正为 **¥10.5**；主控从 ¥11 修正为 **¥13**
- **B 档 ¥151**，原定 ≤ ¥170 的目标仍成立，安全边际比 A 档更宽
- 仍有 **4 项属于未核实估算**（电源适配器、线材、五金、保护板+充电器），合计量级约 ¥40，采购时需落实
- 所有单价为 **2026-09-15 国内电商实价，但不含运费**；小批量采购运费通常占 10%–15%
- 舵机与电池是最容易波动的两项，建议一次性锁定批次

## 6. 技术可行性评审

| 项 | 核算 / 验证 | 结论 |
|---|---|---|
| PWM 通道 | S3 = 8 路，刚好够 8 舵机；C3 = 6 路，必须外挂 PCA9685 | ✅ 可行，S3 无余量 |
| 峰值电流 | 8 舵机堵转 5.6–8 A，电源仅 3 A | ⚠️ **需靠软件限流 + 电容缓冲**，靠电源硬扛不现实 |
| 舵机扭矩 | 单腿承重约 110 g、力臂约 5 cm → 需 ≈0.55 kg·cm；SG90 ≈1.8、MG90S ≈2.2 | ✅ 静态余量约 3 倍；动态冲击下余量收窄，故 B 档升级金属齿 |
| 静态电流 | 8 舵机待机 ≈ 80 mA | ✅ 对续航友好 |
| 通信 | WiFi + HTTP JSON API，参考项目已验证 | ✅ 可行 |
| 结构装配 | 复用已验证 STL，M2 自攻螺丝固定 | ✅ 可行，注意打印公差 |
| 固件移植 | S2 → S3/C3 引脚不同 | ⚠️ 需 2 天适配 |
| 开源合规 | Apache-2.0 | ✅ 可用，需保留声明 |

## 9. 评审通过条件

满足以下全部条件，方可将状态从"待评审"改为"通过"：

1. A1–A4 全部有明确结论
2. M1 的供电带载测试报告出具，且 5V 轨在 2 A 负载下压降 < 0.3 V
3. 舵机样品实测确认是 180° 版本且扭矩达标
4. 成本测算经采购复核，A 档确认 ≤ ¥115
5. 开源许可与出处声明方案确认

**未通过则需要重新评审的触发条件**：供电测试失败且无法通过电容/限流解决；舵机实测扭矩不足；成本超预算 20% 以上。
