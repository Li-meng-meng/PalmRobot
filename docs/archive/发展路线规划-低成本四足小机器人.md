## 0. 前提假设

| 假设项 | 取值 | 说明 |
|---|---|---|
| 团队 | 嵌入式 1 人 + 软件 1 人 + 外观设计 1 人（后置，先不花钱） | |
| **启动资金** | **¥300** | 自有资金 |
| 库存 | **零** | 按单采购、按单生产 |
| 收款模式 | 全额预付款，收钱后采购 | 现金流为正 |
| 供应链 | 淘宝/拼多多件 + 代打打印件（接单后才买） | 不自建产线 |
| 目标市场 | 国内创客/极客/送礼 | 暂不出海 |

### 0.1 先说清楚 ¥300 意味着什么

**¥300 只够做一台样机，没有任何容错空间。** 买错一个件、烧坏一个模组，就要停下来重新攒钱。

所以这个版本的核心策略是三条：

1. **能用免费的先做**（仿真、纸板结构、家里现成的电源）
2. **一次只买一套**，验证通过再买下一套
3. **绝不用自己的钱做第二台**——第二台的钱必须来自用户的预付款

**代价也要说清楚**：这个模式的周期会比正常创业长，从样机到第一笔收入可能要 3–5 个月。这不一定是坏事，但要接受。

## 1. 团队分工与产能

| 角色 | 立刻能做的（零成本） | 后续负责 |
|---|---|---|
| **软件工程师** | **MuJoCo 搭建 8-DOF 四足模型、跑步态仿真、生成演示视频**；网页控制框架 | App、视频动作提取、表情识别、内容制作 |
| **嵌入式工程师** | 梳理引脚与供电方案、写舵机驱动代码（可先不接硬件） | 固件、步态、传感器、试产工艺 |
| **外观设计** | 先免费出 2–3 个方向的概念草图 | 待有钱后再做建模与配色 |

### 1.1 为什么先做仿真（这是 ¥300 模式的关键）

**仿真不花钱，只需要时间，而且能解决两件事：**

1. **验证步态算法**：嵌入式工程师不必等硬件到位，就能把步态逻辑跑通、调好参数，硬件一到直接烧录
2. **产出演示内容**：软件工程师可以用仿真渲染出"机器狗在走路"的视频，用于建号和吸引关注

> 参考项目 sesame-robot 有第三方做的 Rust 3D 仿真环境，说明这条路走得通。你们可以复用它的 URDF/MJCF 模型（Apache-2.0 允许），省掉建模时间。

**但要诚实**：仿真视频不能当作实物演示去卖货。它的作用是**建号、攒粉、招种子用户**，不是收钱。

### 1.2 产能

| 环节 | 单台耗时 | 说明 |
|---|---|---|
| 装配 + 走线 | 1.5–2.5 h | 2 人周末做，一天 6–8 台 |
| 舵机标定 + 测试 | 0.5 h（可脚本化压到 15 分钟） | |
| 3D 打印 | 8–12 h 机时/套 | **你们没有打印机，所以一律代打（¥40–80/套）** |

> 没有打印机反而简化了决策：**打印全部外包**，不需要考虑买机器（¥800+，现在也买不起）。

## 2. 经营模式：全额预付款 + 按单生产

### 2.1 核心逻辑

```
用户下单付款 → 用这笔钱买料 → 生产 → 交付 → 再开下一团
```

**你们自己的钱只用来做第一台样机，之后每一台都是用户的钱在滚动。**

### 2.2 为什么第一团必须限量

| 风险 | 说明 | 对策 |
|---|---|---|
| 交付能力不足 | 三个人都是兼职，做不完会崩 | **第一团限 5 台** |
| 没经验，良率低 | 第一次批量装配必然出问题 | 5 台的返工成本可承受 |
| 承诺了做不到 | 交付延迟 = 信任崩塌 | 第一团承诺 5 周，实际 4 周 |

**第一团只招 5 个人**，做完再开 10 台，再开 20 台。**每一团都是在为下一团攒经验。**

### 2.3 收款纪律（比什么都重要）

| 规矩 | 原因 |
|---|---|
| 走有担保的平台（淘宝小店 / 微店） | 用户敢付，你们也有据可依 |
| **绝不微信私下转账** | 一旦延迟发货，会被当成诈骗 |
| 商品页写明交付周期 + 无条件退款 | 转化率反而更高 |
| 收到钱先留 20% 不动 | 应对退款与返工 |

### 2.4 信任建设（从零开始的团队必须做这件事）

| 动作 | 频率 |
|---|---|
| GitHub 仓库持续提交（证明真在做） | 每周 |
| B 站/小红书发进展（仿真 → 样机 → 装配） | 每周 1 条 |
| 开团后公示进度（采购到货 / 装配中 / 已发货） | 每团 3–4 次 |
| 未发货随时全额退款 | 写在商品页 |

## 5. P0：仿真 + 一台裸机（0–2 月，¥100）

### 5.1 任务顺序

| 顺序 | 任务 | 谁 | 花不花钱 | 完成标志 |
|---|---|---|---|---|
| 1 | **MuJoCo 建模 + 步态仿真** | 软件 | ¥0 | 仿真里能稳定走 1 米 |
| 2 | 引脚与供电方案定稿 | 嵌入式 | ¥0 | 画出接线图 |
| 3 | 采购第一批（¥34.5 试水） | 嵌入式 | ¥34.5 | 舵机能动 |
| 4 | 8 路 PWM + 舵机驱动跑通 | 嵌入式 | ¥0 | 8 个舵机全部可控 |
| 5 | 采购剩余件（¥60.3） | 嵌入式 | ¥60.3 | 件齐 |
| 6 | **裸机装配**（木板/纸板固定） | 嵌入式 | ¥0 | 能站起来 |
| 7 | 步态移植到实机 | 嵌入式 | ¥0 | **走 1 米不摔** |
| 8 | OLED 表情 + 网页遥控 | 软件 | ¥0 | 手机能控制 |
| 9 | **悬崖检测**（红外对管） | 嵌入式 | 从预留里出 ¥5 | 桌边自动停住 |
| 10 | 拍第一条演示视频 | 软件 | ¥0 | 1 分钟片子 |

### 5.2 裸机起步：不要纠结外壳

**你们没有打印机，也没钱代打，所以第一台不要外壳。**

做法：找一块木板或亚克力板（或厚纸板），把 8 个舵机用 M2 螺丝和热熔胶固定成四足布局，四条腿用舵机自带的舵盘当"脚"。这样：

- 成本 ¥0
- 能完整验证步态、供电、表情、悬崖检测
- 视频里虽然"丑"，但**能动的丑狗比静止的漂亮狗更有说服力**，反而容易出内容

**外壳等到第一团有预付款之后再花钱做**（代打一套 ¥40–80，或让外观设计出 3D 模型后一起打）。

> 顺带一个内容红利：**"用纸板做的机器狗"这类视频在 B 站/小红书的传播力，往往比成品更好。** 把"穷"讲成故事，是你们现在唯一的营销资源。

### 5.3 P0 不做的事

- 不买打印机
- 不做外壳与包装
- 不做 App（先用网页）
- 不做视频动作导入

## 6. P1：创始团（2–5 月，零垫资）

### 6.1 核心玩法

**用那台裸机样机的视频，招 5 个创始用户，收全款，然后用这笔钱买料做交付。**

| 项 | 计算 |
|---|---|
| 售价（含打印件套件，创始价） | ¥399 |
| 创始团数量 | 5 台 |
| **预收款** | **¥1,995** |
| 单台成本 | 物料 ¥151 + 代打 ¥50 + 包装 ¥10 + 运费 ¥10 = ¥221 |
| 5 台成本 | **¥1,105** |
| **毛利** | **≈ ¥890** |
| 需自己垫资 | **¥0**（收钱在买料之前） |

### 6.2 创始团怎么招

| 渠道 | 做法 |
|---|---|
| B 站/小红书的粉丝 | 视频结尾说"想参与的可以留言" |
| GitHub / 立创开源社区 | 发项目进展贴 |
| 微信群 | 从评论区转化 |

**5 个人不难找**，这是刻意设计的低门槛——你们需要的是一个能跑通的完整闭环，不是销量。

### 6.3 创始团要额外做的两件事

1. **全程记录**：装配过程的照片、问题、返工，都是后面的内容素材
2. **收集真实反馈**：装配难度、最想玩的玩法、哪里最容易被骂

### 6.4 通过标准

- 5 台全部按期交付（承诺 5 周，实际 ≤4 周）
- 5 位用户里至少 3 位愿意公开评价
- 至少 1 位主动问"能不能买第二台"

> 若 5 台都做不出来，说明产能或工艺有问题，**不要开更大的团**，先解决交付。

## 8. 阶段门（Gate）

| 门 | 时间 | 通过标准 | 不通过怎么办 |

> **Gate 3 尤其重要**：它明确写出"做不成就不做了"的撤退线。提前想好，比事后纠结轻松得多。

| 开源许可 | 要 | 见下 |

### 10.1 开源许可（这条会影响你的商业模式，务必看）

sesame-robot 是 **Apache-2.0**：

1. 你可以商用、改、卖 —— ✅
2. 基于它的图纸做的衍生作品，**必须继续用 Apache-2.0**
3. 所以**任何人都能拿你的图纸做同样的东西卖钱**，这是合法且必然的

**你的护城河只能是这四样：**

| 护城河 | 说明 | 难度 |
|---|---|---|
| 品牌与内容 | 用户认的是"你们这只狗" | 高 |
| 装配工艺与良率 | 同图纸，你良率 95%，别人 60% | 中高 |
| **软件与玩法** | 视频动作、表情系统、动作市场（不开源） | **最高** |
| 迭代速度 | 别人抄完上一版，你已发下一版 | 中 |
