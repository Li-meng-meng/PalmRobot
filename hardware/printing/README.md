## STP（STEP）版打印件 — `stp/` 共 11 件

切片器要 STP、或想在 CAD（SolidWorks / Fusion / FreeCAD）里改件再打，用这份：

| 文件 | 来源 | 说明 |
|---|---|---|
| `Internal-Frame-v122.stp` 等其余 10 件 | 上游整机装配 `../cad/Sesame-ESP32-v122.step` 按零件名拆分 | 原始 B-rep，可编辑；`python ../cad/split_step.py split` 再生成 |
| `Top-Cover-Enclosed-v117.stp` | 同名 STL 转换（上游装配不含顶盖，仓库也只有 STL） | **多面体 B-rep**（每三角形一平面片，8.4MB）；改结构建议重建 CAD 再导出 |

- 拆分以装配体**零件名**为准（R/L 镜像件不靠几何猜）；单实体、体积与外形回读校验过，尺寸与 STL 版差 ≤1mm（腿件上游 v117→v122 演化所致，STP 略大以新为准）。
- 依赖：`pip install cadquery-ocp`（OpenCascade 绑定，OCP 8）。转换工具见 `stl_to_step.py`（顶盖已知"4 三角形共享边"瑕疵在转换时自动去重修复）。

## 打印建议

| 项 | 建议 |
|---|---|
| 材料 | PLA 即可；腿件承力可用 PETG |
| 腿件（R1-R4 / L1-L4） | 4 层壁 + ≥40% 填充（舵机自攻螺丝孔位反复拆装） |
| 机身 / 盖板 | 3 层壁 + 20% 填充足够 |
| 摆放 | 大腿/小腿**侧面平放**，让舵机轴孔轴向接近水平（孔更圆，免打孔）；孔轴竖直的件会有明显椭圆 |
| 支撑 | 腿件一般免支撑；机身骨架视切片器预览补少量 |

**配套硬件**：SG90 9g 180° 舵机 ×8（髋 ×4 + 膝 ×4）、M2 自攻螺丝（舵机固定）、PCA9685 + ESP32-C3 装机身内腔，见 [`../README.md`](../README.md) B 档 BOM。

## 已知瑕疵

- `Top-Cover-Enclosed-v117.stl` 有 **1 条被 4 个三角形共享的边**（上游 CAD 导出的双墙面痕迹，两对重复贴面三角形，非破洞，体积封闭）。PrusaSlicer / Cura / Bambu Studio 都会自动修复；若切片器报警，用 netfabb 或 3D Builder 一键修复即可。其余 10 件全部通过边流形检查（每条边恰好 2 个三角形共享）。
