# hardware/ — 结构件与硬件

## 直接复用的现成资产（不要从零设计）

| 资产 | 来源 | 用途 |
|---|---|---|
| 全套 STL | [dorianborian/sesame-robot](https://github.com/dorianborian/sesame-robot) → `hardware/printing/stl/` | 3D 打印 |
| 完整 CAD (STEP) | 同上 → `hardware/cad/` | 要改结构时用 |
| **多种顶盖** | 同上 → `stl/top-covers/`（猫耳 / 无耳 / 封闭式） | **换壳测试直接用** |
| **磁吸帽子系统** | 同上 → `stl/top-covers/hats/` | **扩展接口可复用其磁吸规范** |

> sesame 已内置磁吸模块化顶盖系统，我们的扩展件接口建议**直接复用它的磁吸接口规范**，省掉一轮结构设计。

## 第一版结构的最小改动

| # | 改动 | 目的 |
|---|---|---|
| 1 | 头部外壳（含 OLED 窗口） | 定义角色 |
| 2 | 身体外壳 | 同上 |
| 3 | 配色（2–3 套） | 出片 |
| 4 | 脚底硅胶垫槽位 | 防滑 |
| 5 | 扩展接口开孔（背/头各 1） | 预留 |
| 6 | 底部运动模块接口 | 模块化 |

**不要动**：腿部连杆、舵机安装位、舵盘连接方式 —— 改了步态要重调（1–2 周工时）。

## 3D 能力要求

只需要 **L2：会用 Tinkercad 改现成模型**（学 2–3 小时）。最难的部分（机构设计）已由 sesame 提供。

## 打印检查清单

| 检查项 | 标准 |
|---|---|
| 最小壁厚 | ≥ 1.2 mm（承力处 ≥ 2 mm） |
| 螺丝柱 | 外径加厚，孔留 0.2–0.3 mm 公差 |
| 悬垂角度 | > 45° 需加支撑 |
| 舵机安装位 | 留 0.2–0.3 mm 间隙 |

> 第一套打印前，**先打 1 个关键件试装**，再打整套。
