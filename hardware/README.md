## 模块化运动平台

| 模块 | 执行器 | 模块成本 | I2C 地址 |
|---|---|---|---|
| 四足（标配） | 8× SG90 180° | ≈ ¥60 | 0x40 |
| 轮式 | 2× SG90 360° | ≈ ¥27 | 0x41 |
| 履带 | 2× SG90 360° | ≈ ¥40 | 0x42 |
| 双足 | 4× SG90 + 尾撑 | ≈ ¥45 | 0x43 |
| 桌宠底座 | 无 | ≈ ¥5 | 0x44 |

**技术要点**

- 运动模块**自带 PCA9685**，本体只提供 4pin（5V/GND/SDA/SCL）—— 与扩展口统一
- 用 **I2C 地址区分模块**，上电自动识别，零成本
- 轮式与履带用 **360° 舵机**驱动（与 180° 版同价，PWM 调速，不需要电机驱动板）

## 硬约束

| # | 约束 | 原因 |
|---|---|---|
| 1 | **舵机必须 180°** | 360° 版无法定位角度 |
| 2 | 电源轨并 **1000 µF 电容** | 8 舵机峰值 5.6–8 A |
| 3 | **ESP32-C3 没有摄像头接口、不支持 PSRAM** | 要加摄像头必须换 ESP32-S3（+¥20–30），**采购前必须定** |

## 打印检查清单

| 检查项 | 标准 |
|---|---|
| 最小壁厚 | ≥ 1.2 mm（承力处 ≥ 2 mm） |
| 螺丝柱 | 外径加厚，孔留 0.2–0.3 mm 公差 |
| 悬垂角度 | > 45° 需加支撑（尽量避免） |
| 舵机安装位 | 留 0.2–0.3 mm 间隙 |
| 零件数 | 尽量少（每多一件都增加装配时间与代打成本） |

> 第一套打印前，**先打 1 个关键件试装**，再打整套。
